# Личный сайт

Статический сайт без сборки. Для локального просмотра: `python3 -m http.server 8000`, затем открыть `http://localhost:8000`.

## Галереи в страницах и будущих записях блога

Подключить `css/style.css`, `css/gallery.css` и один раз `js/gallery.js` с атрибутом `defer`. Пути указываются относительно страницы.

В нужном месте статьи добавить блок:

```html
<div class="gallery" aria-label="Фотографии с поездки">
  <a href="images/trip.jpg" data-caption="Необязательная подпись">
    <img class="gallery-photo" src="images/trip.jpg" alt="Описание фотографии">
  </a>
  <!-- Добавляйте следующие ссылки с изображениями сюда. -->
</div>
```

Количество фотографий и галерей произвольное. Счётчики и просмотрщик создаются автоматически, каждая галерея листается отдельно. Подпись берётся из `data-caption`, а при его отсутствии — из `alt`. Без JavaScript ссылки открывают исходные изображения.

По умолчанию превью заполняют всю область с обрезкой краёв, а просмотрщик показывает полный кадр. Положение кадра можно изменить через `style="--gallery-position: center 30%"` на отдельной ссылке или всей галерее. Чтобы показать превью целиком (например, скриншот), задайте `style="--gallery-fit: contain"`. Ссылка `href` может вести на оригинал, а `img src` — на уменьшенное превью; у превью желательно указать реальные `width` и `height`.

Для новой записи можно скопировать существующую страницу, поменять заголовок и текст, добавить любое количество таких блоков. Галереям не нужны отдельные идентификаторы, списки файлов в JavaScript или регистрация новой страницы.
